# Enterprise SIEM Deployment Project

## Overview

This repository showcases the end-to-end management and delivery of an Enterprise Security Information and Event Management (SIEM) implementation project. It demonstrates project management best practices, including planning, execution, stakeholder engagement, risk management, governance, reporting, and successful deployment.

The project was executed across multiple infrastructure, security, network, and application teams to establish centralized log management, security monitoring, and operational visibility.

---

## Project Information

- **Project Name:** Enterprise SIEM Deployment
- **Role:** Project Manager
- **Duration:** 6 Months
- **Methodology:** Hybrid (Agile + Waterfall Governance)
- **Domain:** Cybersecurity / Security Operations
- **Project Size:** 100+ Log Sources
- **Teams Involved:** Security, Infrastructure, Network, Application Support, Vendors

---

## Business Objective

Organizations often face challenges in monitoring security events across multiple systems and applications. This project aimed to centralize security monitoring by implementing a SIEM platform capable of collecting, correlating, and analyzing logs from diverse sources.

### Key Objectives

- Centralize security log collection
- Improve threat detection capabilities
- Enhance incident investigation efficiency
- Standardize security reporting
- Reduce Mean Time to Detect (MTTD)
- Improve compliance and audit readiness
